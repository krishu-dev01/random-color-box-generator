# Random Color Box Generator

A lightweight and interactive JavaScript project that dynamically assigns random RGB colors to four styled boxes using DOM manipulation.

## 🛠️ Features & Concepts Practiced
- **Dynamic Color Generation**: Utilizes `Math.random()` and `Math.floor()` to generate RGB values (`rgb(r, g, b)`).
- **DOM Selection**: Uses `document.querySelectorAll()` to target multiple box elements.
- **NodeList Iteration**: Uses `.forEach()` loop to iterate through all selected elements cleanly.
- **Inline Styling**: Updates CSS properties dynamically via JavaScript (`element.style.backgroundColor`).

## 💻 Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run
1. Download or clone this repository.
2. Open `index.html` in any modern web browser.
3. Refresh the page to generate new random colors for each box!
